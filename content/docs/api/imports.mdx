---
title: Statement and file imports
description: Upload a statement, scan it, review the rows and commit them to the ledger.
---

The import flow is upload, scan, parse, review, then commit. Nothing is written to the ledger until you commit.

Until PDF and photo reading is built, a PDF or photo import answers that you should enter the rows manually.
