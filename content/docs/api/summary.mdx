Use these actual workspace routes instead of the former `/summary` alias. Net worth, income and spending are decimal strings. Missing FX and valuation coverage remain explicit; lending exchanges cash and receivable without inventing income/spending.

Private operations require an authorized Clerk user bearer and workspace membership. Optional/sensitive services retain their policy/entitlement/fresh-authentication gates.

| Complete route | Authentication | Required operation headers | Declared success |
| --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/scenarios/page` | Clerk user bearer | — | 200 application/json RecordPage_ScenarioResponse_ |
| `GET /api/v1/workspaces/{workspace_id}/dashboard` | Clerk user bearer | — | 200 application/json DashboardResponse |
| `GET /api/v1/workspaces/{workspace_id}/forecast` | Clerk user bearer | — | 200 application/json ForecastPage |
| `GET /api/v1/workspaces/{workspace_id}/cashflow` | Clerk user bearer | — | 200 application/json CashflowResponse |
| `POST /api/v1/workspaces/{workspace_id}/scenarios/preview` | Clerk user bearer | — | 200 application/json ScenarioPreview |
| `GET /api/v1/workspaces/{workspace_id}/scenarios` | Clerk user bearer | — | 200 application/json ScenarioResponse[] |
| `POST /api/v1/workspaces/{workspace_id}/scenarios` | Clerk user bearer | `Idempotency-Key` | 200 application/json ScenarioResponse |
| `GET /api/v1/workspaces/{workspace_id}/activity-insights` | Clerk user bearer | — | 200 application/json ActivityInsights |
| `GET /api/v1/workspaces/{workspace_id}/upcoming-obligations` | Clerk user bearer | — | 200 application/json UpcomingPage |
