title: Financial Summary

---

`GET /summary`

Calculates a dated financial summary across explicitly requested own-data domains, returning total assets, liabilities, net worth, contributing resources, and exclusion reasons.

---

## Authorization

- **Scopes Required**: `reports:read` **plus** the scope for each domain listed in `domains`:
  - `accounts:read` (if `accounts` is included)
  - `assets:read` (if `assets` is included)
  - `liabilities:read` (if `liabilities` is included)
- **Plan Requirement**: Active Paid subscription

---

## Query Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `domains` | string | **Yes** | Comma-separated list containing `accounts`, `assets`, and/or `liabilities`. |
| `as_of` | date | No | Valuation cutoff date (`YYYY-MM-DD`). Defaults to current date in user timezone. |

<Callout type="warn" title="Net Worth Availability">
  The `net_worth` field will be `null` unless all three domains (`accounts,assets,liabilities`) are requested, authorized, and provide sufficient valuation coverage.
</Callout>

---

## Example Request

```bash
curl --fail-with-body --get \
  "https://api.farz.app/api/developer/v1/summary" \
  -H "Authorization: Bearer $FARZ_API_KEY" \
  -H 'Accept: application/json' \
  --data-urlencode 'domains=accounts,assets,liabilities' \
  --data-urlencode 'as_of=2026-10-10'
```
