---
title: Dashboard and summary
description: Dashboard data and the activity summary for one workspace.
---

A value that cannot be calculated is `null`. It is not `0`. Read the coverage fields before you use a total.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/dashboard` | Get Dashboard | Signed-in user (Clerk bearer) | none | `month`, `account_id`, `ownership`, `display_currency`, `history_points`, `to_review_limit`, `to_review_offset` | none | 200 `DashboardResponse` |
| `GET /api/v1/workspaces/{workspace_id}/dashboard/breakdowns/{total}` | Drill down from a dashboard total to the items, rates and exclusions behind it | Signed-in user (Clerk bearer) | none | `month`, `account_id`, `ownership`, `display_currency`, `history_points`, `to_review_limit`, `to_review_offset` | none | 200 `TotalBreakdown` |

`*` marks a required query parameter. Path parameters are listed in the route.

Field types come from the contract. Money fields are decimal strings. Nullable fields can be `null`.
