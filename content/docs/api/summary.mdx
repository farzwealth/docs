---
title: Dashboard and summary
description: Dashboard data and the activity summary for one workspace.
---

A value that cannot be calculated is `null`. It is not `0`. Read the coverage fields before you use a total.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/dashboard` | Get Dashboard | Signed-in user (Clerk bearer) | none | none | none | 200 `DashboardResponse` |

`*` marks a required query parameter. Path parameters are listed in the route.

## Models

Field types come from the contract. Money fields are decimal strings. Nullable fields can be `null`.
