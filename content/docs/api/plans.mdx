---
title: Plans and trial
description: Read the current plan and its features, read plan history, and start a trial.
---

A trial lasts 30 days and can be started once per verified email. The plan response shows whether the developer API and MCP are available to your account.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/me/plan` | Current Personal Plan | Signed-in user (Clerk bearer) | none | none | none | 200 `PersonalPlanResponse` |
| `GET /api/v1/workspaces/{workspace_id}/plan` | Current Plan | Signed-in user (Clerk bearer) | none | none | none | 200 `PlanResponse` |
| `GET /api/v1/workspaces/{workspace_id}/plan/features` | Plan Features | Signed-in user (Clerk bearer) | none | none | none | 200 `FeatureMatrix` |
| `GET /api/v1/workspaces/{workspace_id}/plan/history` | History | Signed-in user (Clerk bearer) | none | `before_revision`, `limit` | none | 200 `PlanHistoryPage` |
| `POST /api/v1/workspaces/{workspace_id}/plan/refresh` | Refresh | Signed-in user (Clerk bearer) | none | none | none | 200 `PlanObservation` |
| `GET /api/v1/workspaces/{workspace_id}/trial` | App Trial Eligibility | Signed-in user (Clerk bearer) | none | none | none | 200 `TrialEligibility` |
| `POST /api/v1/workspaces/{workspace_id}/trial` | Start App Trial | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `TrialStart` | 201 `PlanResponse` |

`*` marks a required query parameter. Path parameters are listed in the route.
