---
title: Notifications and reminders
description: In-app notifications, preferences, reminder schedules and delivery status.
---

**Status: In testing for in-app notifications.** **Planned for email.** Email needs the verified mail sending domain, which is not yet set up.

Read the inbox and your preferences. Email delivery status appears only after email is turned on.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/email/delivery-notice` | Email Delivery Notice | Signed-in user (Clerk bearer) | none | none | none | 200 `DeliveryNotice` |
| `POST /api/v1/workspaces/{workspace_id}/notifications/actions` | Actions | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `InboxActions` | 200 `ActionReceipt` |
| `GET /api/v1/workspaces/{workspace_id}/notifications/delivery-health` | Delivery Health | Signed-in user (Clerk bearer) | none | none | none | 200 `DeliveryHealthResponse` |
| `GET /api/v1/workspaces/{workspace_id}/notifications/inbox` | Inbox | Signed-in user (Clerk bearer) | none | `unread_only`, `include_dismissed`, `include_snoozed`, `kind`, `limit`, `cursor` | none | 200 `InboxPage` |
| `GET /api/v1/workspaces/{workspace_id}/notifications/preferences` | Get Preferences | Signed-in user (Clerk bearer) | none | none | none | 200 `PreferenceResponse` |
| `PUT /api/v1/workspaces/{workspace_id}/notifications/preferences` | Put Preferences | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `PreferenceWrite` | 200 `PreferenceResponse` |
| `POST /api/v1/workspaces/{workspace_id}/notifications/schedule` | Schedule | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `ScheduleInput` | 200 `ScheduleReceipt` |
| `POST /api/v1/workspaces/{workspace_id}/notifications/schedule-preview` | Reminders | Signed-in user (Clerk bearer) | none | none | none | 200 `ReminderPreview` |
| `GET /api/v1/workspaces/{workspace_id}/notifications/{notification_id}/delivery` | Delivery Status | Signed-in user (Clerk bearer) | none | none | none | 200 `DeliveryResponse` |
| `POST /api/v1/workspaces/{workspace_id}/notifications/{notification_id}/delivery/cancel` | Delivery Cancel | Signed-in user (Clerk bearer) | none | none | none | 200 `DeliveryResponse` |
| `POST /api/v1/workspaces/{workspace_id}/notifications/{notification_id}/delivery/execute` | Delivery Execute | Signed-in user (Clerk bearer) | none | none | none | 200 `DeliveryResponse` |
| `POST /api/v1/workspaces/{workspace_id}/notifications/{notification_id}/delivery/receipts` | Delivery Receipts | Signed-in user (Clerk bearer) | none | none | none | 200 `DeliveryResponse` |
| `POST /api/v1/workspaces/{workspace_id}/notifications/{notification_id}/delivery/reconcile` | Delivery Reconcile | Signed-in user (Clerk bearer) | none | none | `ReconcileDelivery` | 200 `DeliveryResponse` |

`*` marks a required query parameter. Path parameters are listed in the route.
