---
title: Valuation snapshots
description: Save and read dated valuation snapshots, and run catch-up jobs for missing closed months.
---

A saved snapshot keeps the inputs it was made from. Later price changes do not rewrite it.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshot-coverage` | Discover missing closed-month snapshots | Signed-in user (Clerk bearer) | none | `from_period*`, `through_period*` | none | 200 `SnapshotCoverage` |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshot-jobs` | List Snapshot Jobs | Signed-in user (Clerk bearer) | none | `limit`, `state`, `cursor` | none | 200 `SnapshotJobPage` |
| `POST /api/v1/workspaces/{workspace_id}/valuation-snapshot-jobs` | Enqueue Snapshot Jobs | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `SnapshotJobsWrite` | 202 `SnapshotJobsResponse` |
| `POST /api/v1/workspaces/{workspace_id}/valuation-snapshot-jobs/catch-up` | Catch Up Snapshot Jobs | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `SnapshotCatchupWrite` | 202 `SnapshotCatchupResponse` |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshot-jobs/{task_id}` | Get Snapshot Job | Signed-in user (Clerk bearer) | none | none | none | 200 `SnapshotJobStatus` |
| `POST /api/v1/workspaces/{workspace_id}/valuation-snapshot-jobs/{task_id}/cancel` | Cancel Snapshot Job | Signed-in user (Clerk bearer) | none | none | none | 200 `SnapshotJobStatus` |
| `POST /api/v1/workspaces/{workspace_id}/valuation-snapshot-jobs/{task_id}/run` | Run Snapshot Job | Signed-in user (Clerk bearer) | none | none | `SnapshotJobRun` | 200 `SnapshotJobStatus` |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshots` | List Valuation Snapshots | Signed-in user (Clerk bearer) | none | `period*` | none | 200 array of `ValuationSnapshotSummary` |
| `POST /api/v1/workspaces/{workspace_id}/valuation-snapshots` | Save Valuation Snapshot | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `ValuationSnapshotWrite` | 200 `ValuationSnapshotResponse` |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshots/page` | list_valuation_snapshots (paged) | Signed-in user (Clerk bearer) | none | `period*`, `limit`, `cursor` | none | 200 `ListValuationSnapshotsPage` |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshots/preview` | Preview Valuation Snapshot | Signed-in user (Clerk bearer) | none | `period*` | none | 200 `ValuationPreview` |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshots/{snapshot_id}` | Get Valuation Snapshot | Signed-in user (Clerk bearer) | none | none | none | 200 `ValuationSnapshotResponse` |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshots/{snapshot_id}/report.csv` | Export Saved Valuation | Signed-in user (Clerk bearer) | none | none | none | 200 (no body) |
| `GET /api/v1/workspaces/{workspace_id}/valuation-snapshots/{snapshot_id}/report.html` | Print Saved Valuation | Signed-in user (Clerk bearer) | none | none | none | 200 (no body) |

`*` marks a required query parameter. Path parameters are listed in the route.
