Use `/valuation-snapshots`, not the former `/valuations` alias. Previewing, recording and downloading are separate operations; recorded snapshots preserve their dated basis. Private report downloads require recent signed authentication and export allowance. CSV/HTML are actual response types.

Private operations require an authorized Clerk user bearer and workspace membership. Optional/sensitive services retain their policy/entitlement/fresh-authentication gates.

Snapshot jobs expose explicit creation/status/run/cancel contracts. Job admission or forecast completion is not an external valuation or automatic background scheduling guarantee.
