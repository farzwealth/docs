`GET /valuations`

Reads original, immutable monthly portfolio valuation snapshots and correction lineage without recomputing against present-day market prices.

---

## Authorization

- **Scope Required**: `valuations:read`
- **Plan Requirement**: Active Paid subscription

---

## Query Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `start` | date | **Yes** | Inclusive beginning of saved cutoff date range (`YYYY-MM-DD`). |
| `end` | date | **Yes** | Inclusive end of saved cutoff date range (`YYYY-MM-DD`). Max range: **366 calendar days**. |
| `period` | date | No | First-of-month date matching the selected range (`YYYY-MM-DD`). |
| `limit` | integer | No | Page limit between `1` and `100` (default: `50`). |
| `cursor` | string | No | Continuation cursor from `next_cursor`. |

---

## Example Request

```bash
curl --fail-with-body --get \
  "https://api.farz.app/api/developer/v1/valuations" \
  -H "Authorization: Bearer $FARZ_API_KEY" \
  -H 'Accept: application/json' \
  --data-urlencode 'start=2026-01-01' \
  --data-urlencode 'end=2026-10-10' \
  --data-urlencode 'limit=50'
```
