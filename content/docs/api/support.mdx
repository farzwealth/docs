---
title: Support tickets
description: Open a support ticket, read its messages and reply.
---

Use a ticket for account or product problems. Do not put a password or a full card number in a ticket.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/support/tickets` | Page | Signed-in user (Clerk bearer) | none | `before_id`, `limit` | none | 200 `TicketPage` |
| `POST /api/v1/workspaces/{workspace_id}/support/tickets` | Create | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `TicketInput` | 201 `TicketView` |
| `GET /api/v1/workspaces/{workspace_id}/support/tickets/{ticket_id}` | Selected | Signed-in user (Clerk bearer) | none | none | none | 200 `TicketView` |
| `POST /api/v1/workspaces/{workspace_id}/support/tickets/{ticket_id}/actions` | Act | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `TicketAction` | 200 `TicketView` |
| `GET /api/v1/workspaces/{workspace_id}/support/tickets/{ticket_id}/messages` | Messages | Signed-in user (Clerk bearer) | none | `after_sequence`, `limit` | none | 200 `MessagePage` |

`*` marks a required query parameter. Path parameters are listed in the route.

## Models

Field types come from the contract. Money fields are decimal strings. Nullable fields can be `null`.

### `TicketPage`

| Field | Type | Required |
| --- | --- | --- |
| `items` | array of TicketView | yes |
| `next_before_id` | string (uuid) (nullable) | yes |

### `TicketInput`

| Field | Type | Required |
| --- | --- | --- |
