---
title: Privacy, consents and account deletion
description: Record consents, file privacy requests, read and download your records, and manage account deletion.
---

Account deletion starts a grace period. You can cancel the deletion before it finishes.

Exports and privacy reports are downloaded through the request they belong to.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/account-deletion` | Account Deletion Status | Signed-in user (Clerk bearer) | none | none | none | 200 `DeletionStatus` |
| `POST /api/v1/workspaces/{workspace_id}/account-deletion` | Request Account Deletion | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `DeletionRequest` | 201 `DeletionStatus` |
| `POST /api/v1/workspaces/{workspace_id}/account-deletion/cancel` | Cancel Account Deletion | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `DeletionCancel` | 200 `DeletionStatus` |
| `GET /api/v1/workspaces/{workspace_id}/consents` | Consent Status | Signed-in user (Clerk bearer) | none | none | none | 200 array of `ConsentStatus` |
| `POST /api/v1/workspaces/{workspace_id}/consents` | Record Consent | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `ConsentWrite` | 200 `ConsentEventResponse` |
| `GET /api/v1/workspaces/{workspace_id}/consents/page` | consent_status (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `ConsentStatusPage` |
| `GET /api/v1/workspaces/{workspace_id}/consents/{purpose}/history` | Consent History | Signed-in user (Clerk bearer) | none | `before`, `limit` | none | 200 array of `ConsentEventResponse` |
| `GET /api/v1/workspaces/{workspace_id}/privacy/requests` | List Privacy Requests | Signed-in user (Clerk bearer) | none | `offset`, `limit` | none | 200 `PrivacyRequestPage` |
| `POST /api/v1/workspaces/{workspace_id}/privacy/requests` | Submit Privacy Request | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `PrivacyRequestInput` | 201 `PrivacyRequestResponse` |
| `GET /api/v1/workspaces/{workspace_id}/privacy/requests/{request_id}` | Read Privacy Request | Signed-in user (Clerk bearer) | none | none | none | 200 `PrivacyRequestResponse` |
| `POST /api/v1/workspaces/{workspace_id}/privacy/requests/{request_id}/actions` | Privacy Request Action | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `PrivacyRequestAction` | 200 `PrivacyRequestResponse` |
| `GET /api/v1/workspaces/{workspace_id}/privacy/requests/{request_id}/download.json` | Download Privacy Json | Signed-in user (Clerk bearer) | none | `offset`, `limit` | none | 200 object |
| `GET /api/v1/workspaces/{workspace_id}/privacy/requests/{request_id}/history` | Privacy Request History | Signed-in user (Clerk bearer) | none | `offset`, `limit` | none | 200 array of `PrivacyRequestEventResponse` |
| `GET /api/v1/workspaces/{workspace_id}/privacy/requests/{request_id}/report.csv` | Download Privacy Csv | Signed-in user (Clerk bearer) | none | `offset`, `limit` | none | 200 (no body) |
| `GET /api/v1/workspaces/{workspace_id}/privacy/requests/{request_id}/report.html` | Download Privacy Html | Signed-in user (Clerk bearer) | none | `offset`, `limit` | none | 200 (no body) |

`*` marks a required query parameter. Path parameters are listed in the route.
