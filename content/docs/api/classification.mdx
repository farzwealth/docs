---
title: Classifications and merchant rules
description: Save classifications and merchant rules, and run classification batches.
---

A merchant rule suggests a category for future entries. A classification batch applies a rule to several entries at once.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/classifications` | Get Classifications | Signed-in user (Clerk bearer) | none | none | none | 200 array of `ClassificationResponse` |
| `POST /api/v1/workspaces/{workspace_id}/classifications` | Save Classification | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `ClassificationWrite` | 200 `ClassificationResponse` |
| `GET /api/v1/workspaces/{workspace_id}/classifications/page` | Classification Page | Signed-in user (Clerk bearer) | none | `limit`, `cursor`, `q`, `sort`, `kind`, `archived` | none | 200 `RecordPage_ClassificationResponse_` |
| `GET /api/v1/workspaces/{workspace_id}/merchant-rules` | Get Merchant Rules | Signed-in user (Clerk bearer) | none | none | none | 200 array of `MerchantRuleResponse` |
| `POST /api/v1/workspaces/{workspace_id}/merchant-rules` | Save Merchant Rule | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `MerchantRuleWrite` | 200 `MerchantRuleResponse` |
| `GET /api/v1/workspaces/{workspace_id}/merchant-rules/page` | get_merchant_rules (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `GetMerchantRulesPage` |
| `POST /api/v1/workspaces/{workspace_id}/merchant-rules/suggestions` | Rule Suggestions | Signed-in user (Clerk bearer) | none | none | `RuleLookup` | 200 array of `MerchantRuleResponse` |

`*` marks a required query parameter. Path parameters are listed in the route.

## Models

Field types come from the contract. Money fields are decimal strings. Nullable fields can be `null`.
