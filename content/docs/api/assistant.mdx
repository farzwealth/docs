---
title: Assistant
description: Ask the assistant for help, and confirm, review or undo the actions it prepares.
---

**Status: In testing.** The assistant runs in alpha for one named tester. Usage is capped each month.

The assistant can ask a clarifying question and prepare an action. Nothing runs until you confirm the action.

After an action runs, you can review it or undo it.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/me/ai-availability` | Availability | Signed-in user (Clerk bearer) | none | none | none | 200 `AIAvailability` |
| `POST /api/v1/me/ai-help` | Help Response | Signed-in user (Clerk bearer) | none | none | `AIHelpInput` | 200 `AIHelpResponse` |
| `POST /api/v1/workspaces/{workspace_id}/assistant/clarification` | Clarify | Signed-in user (Clerk bearer) | none | none | `ClarificationInput` | 200 `ClarificationResponse` |
| `POST /api/v1/workspaces/{workspace_id}/assistant/requests` | Enqueue | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `AssistantInput` | 202 `AssistantResponse` |
| `GET /api/v1/workspaces/{workspace_id}/assistant/requests/{request_id}` | Get Request | Signed-in user (Clerk bearer) | none | none | none | 200 `AssistantResponse` |
| `GET /api/v1/workspaces/{workspace_id}/assistant/requests/{request_id}/action` | Action | Signed-in user (Clerk bearer) | none | none | none | 200 `ActionReview` |

| `POST /api/v1/workspaces/{workspace_id}/assistant/requests/{request_id}/action/review` | Review Action | Signed-in user (Clerk bearer) | none | none | none | 200 `ActionReview` |
| `POST /api/v1/workspaces/{workspace_id}/assistant/requests/{request_id}/action/undo` | Undo Action | Signed-in user (Clerk bearer) | none | none | `ActionConfirmation` | 200 `ActionReview` |
| `POST /api/v1/workspaces/{workspace_id}/assistant/requests/{request_id}/action/undo-review` | Review Undo | Signed-in user (Clerk bearer) | none | none | none | 200 `ActionReview` |
| `POST /api/v1/workspaces/{workspace_id}/assistant/requests/{request_id}/cancel` | Cancel | Signed-in user (Clerk bearer) | none | none | none | 200 `AssistantResponse` |
| `POST /api/v1/workspaces/{workspace_id}/assistant/requests/{request_id}/execute` | Execute | Signed-in user (Clerk bearer) | none | none | none | 200 `AssistantResponse` |

`*` marks a required query parameter. Path parameters are listed in the route.
