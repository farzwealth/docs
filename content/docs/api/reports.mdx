Create a scoped export task, inspect/execute its state according to the declared contract, then download a ready result. Fresh signed authentication, encrypted consistent snapshots, expiry and bounded export allowance apply. Lending-linked reports conditionally use version5 with loan/repayment IDs; older shapes remain when lending is absent. This is a transaction report, not complete privacy portability or the former generic `/reports?kind=...` service.

Private operations require an authorized Clerk user bearer and workspace membership. Optional/sensitive services retain their policy/entitlement/fresh-authentication gates.

The reference also covers activity/obligation/account statements, ledger queries and durable report exports. Download formats and task execution differ by family; inspect each declared contract. [Owned-record exports](/docs/api/owned-records) use a separate15-minute manifest workflow.
