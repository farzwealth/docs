---
title: Reports and exports
description: Create export jobs for statements, transactions, valuations and owned records, then download them.
---

An export runs as a job. Poll the job status, then download the file with the link the status call returns.

Reports are generated files. JSON and CSV exports are machine-readable. HTML routes are printable pages.
