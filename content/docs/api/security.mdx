---
title: Sessions and devices
description: List registered sessions and devices, preview and revoke a session, and read the revocation history.
---

Preview a revocation before you run it, to see what it affects.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/me/devices` | Personal Registered Sessions | Signed-in user (Clerk bearer) | none | none | none | 200 array of `SessionDeviceResponse` |
| `POST /api/v1/me/devices` | Personal Register Session | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `SessionRegistrationWrite` | 200 `SessionRegistrationResponse` |
| `GET /api/v1/me/devices/page` | personal_registered_sessions (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `PersonalRegisteredSessionsPage` |
| `GET /api/v1/me/devices/{session_id}/revoke` | Personal Revoke Status | Signed-in user (Clerk bearer) | none | none | none | 200 `SessionRevokeStatus` |
| `POST /api/v1/me/devices/{session_id}/revoke` | Personal Revoke Request | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `SessionRevokeWrite` | 202 `SessionRevokeStatus` |
| `POST /api/v1/me/devices/{session_id}/revoke/execute` | Personal Execute Revoke | Signed-in user (Clerk bearer) | none | none | none | 200 `SessionRevokeStatus` |
| `GET /api/v1/me/devices/{session_id}/revoke/history` | Personal Revoke History | Signed-in user (Clerk bearer) | none | none | none | 200 array of `SessionRevokeStatus` |
| `GET /api/v1/me/devices/{session_id}/revoke/history/page` | personal_revoke_history (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `PersonalRevokeHistoryPage` |
| `POST /api/v1/me/devices/{session_id}/revoke/preview` | Personal Revoke Preview | Signed-in user (Clerk bearer) | none | none | `SessionRevokeReview` | 200 `SessionRevokePreview` |
| `GET /api/v1/workspaces/{workspace_id}/security/sessions` | Registered Security Sessions | Signed-in user (Clerk bearer) | none | none | none | 200 array of `SessionRegistrationResponse` |
| `POST /api/v1/workspaces/{workspace_id}/security/sessions` | Register Security Session | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `SessionRegistrationWrite` | 200 `SessionRegistrationResponse` |
| `GET /api/v1/workspaces/{workspace_id}/security/sessions/page` | registered_security_sessions (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `RegisteredSecuritySessionsPage` |
| `POST /api/v1/workspaces/{workspace_id}/security/sessions/{session_id}/block` | Block Security Session | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `SessionBlockWrite` | 200 `SessionBlockResponse` |
| `POST /api/v1/workspaces/{workspace_id}/security/sessions/{session_id}/block/preview` | Preview Security Session Block | Signed-in user (Clerk bearer) | none | none | `SessionBlockReview` | 200 `SessionBlockPreview` |

`*` marks a required query parameter. Path parameters are listed in the route.

## Models

Field types come from the contract. Money fields are decimal strings. Nullable fields can be `null`.
