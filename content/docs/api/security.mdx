---
title: Session inventory and device controls
description: Current unified API contracts, workflow and activation boundaries.
---

Workspace session inventory/local blocking and `/me/devices` provider-session management are separate contracts. Use the shared Clerk user bearer, current ownership and signed recent authentication for sensitive previews/confirmations. Bind confirmations to the current revision/digest and retain a UUID command key where declared.

Local Farz denial is not proof that Clerk has revoked a token. Registered-session inventory is not a complete discovery or revocation guarantee for unregistered sessions. The provider execution path requires separately approved management policy/credentials and is not activated by a successful local block. Ambiguous submitted outcomes remain unknown; recovery inspects provider state without automatically repeating revocation. Inspect authoritative history and provider outcome before claiming upstream logout.

Other-account/session identifiers do not grant access. This documentation does not certify native security acceptance, full concurrent-session inventory or deferred security-review findings.

| Complete route | Authentication | Required operation headers | Declared success |
| --- | --- | --- | --- |

| `POST /api/v1/workspaces/{workspace_id}/security/sessions/{session_id}/block/preview` | Clerk user bearer | — | 200 application/json SessionBlockPreview |
| `POST /api/v1/workspaces/{workspace_id}/security/sessions/{session_id}/block` | Clerk user bearer | `Idempotency-Key` | 200 application/json SessionBlockResponse |
| `GET /api/v1/me/devices` | Clerk user bearer | — | 200 application/json SessionDeviceResponse[] |
| `POST /api/v1/me/devices` | Clerk user bearer | `Idempotency-Key` | 200 application/json SessionRegistrationResponse |
| `POST /api/v1/me/devices/{session_id}/revoke/preview` | Clerk user bearer | — | 200 application/json SessionRevokePreview |
| `POST /api/v1/me/devices/{session_id}/revoke` | Clerk user bearer | `Idempotency-Key` | 202 application/json SessionRevokeStatus |

| `POST /api/v1/me/devices/{session_id}/revoke/execute` | Clerk user bearer | — | 200 application/json SessionRevokeStatus |
