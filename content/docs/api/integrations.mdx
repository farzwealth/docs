---
title: Personal API keys and assistant connectors
description: Issue and revoke personal API keys, and approve or revoke assistant connectors for MCP.
---

**Status: In testing, by staff-granted beta access only.** These routes need a Paid plan or a staff-granted beta access grant.

A personal API key secret is shown once, when it is created. Keys expire in 1 to 90 days. The default is 30 days.

A connector approval lets one assistant client read your data. You can revoke it at any time.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/integrations/keys` | Inventory | Signed-in user (Clerk bearer) | none | none | none | 200 array of `KeyView` |

`*` marks a required query parameter. Path parameters are listed in the route.
