`GET /goals`

Inspect personal financial savings goals, target dates, recorded progress, and projected completion estimates.

---

## Authorization

- **Scope Required**: `goals:read`
- **Plan Requirement**: Active Paid subscription

---

## Query Parameters

| Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `active` | boolean | No | Filter by active planning status (`true` or `false`). Omission returns both. |
| `limit` | integer | No | Page limit between `1` and `100` (default: `50`). |
| `cursor` | string | No | Continuation cursor from `next_cursor`. |

---

## Example Request

```bash
curl --fail-with-body --get \
  "https://api.farz.app/api/developer/v1/goals" \
  -H "Authorization: Bearer $FARZ_API_KEY" \
  -H 'Accept: application/json' \
  --data-urlencode 'active=true' \
  --data-urlencode 'limit=20'
```

---
