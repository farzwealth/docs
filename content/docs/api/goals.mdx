---
title: Goals and scenarios
description: Save goals and what-if scenarios.
---

Goal and scenario projections are estimates under the assumptions shown with them. They are not forecasts of return.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/goals` | Get Goals | Signed-in user (Clerk bearer) | none | none | none | 200 array of `GoalResponse` |
| `POST /api/v1/workspaces/{workspace_id}/goals` | Save Goal | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `GoalWrite` | 200 `GoalResponse` |
| `GET /api/v1/workspaces/{workspace_id}/goals/page` | Goal Page | Signed-in user (Clerk bearer) | none | `limit`, `cursor`, `q`, `sort`, `currency`, `active`, `achieved`, `on_track` | none | 200 `RecordPage_GoalResponse_` |
| `GET /api/v1/workspaces/{workspace_id}/scenarios` | Get Scenarios | Signed-in user (Clerk bearer) | none | none | none | 200 array of `ScenarioResponse` |
| `POST /api/v1/workspaces/{workspace_id}/scenarios` | Save Scenario | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `ScenarioWrite` | 200 `ScenarioResponse` |
| `GET /api/v1/workspaces/{workspace_id}/scenarios/page` | Scenario Page | Signed-in user (Clerk bearer) | none | `limit`, `cursor`, `q`, `sort`, `currency`, `kind`, `has_deficit` | none | 200 `RecordPage_ScenarioResponse_` |
| `POST /api/v1/workspaces/{workspace_id}/scenarios/preview` | Preview Scenario | Signed-in user (Clerk bearer) | none | none | `ScenarioWrite` | 200 `ScenarioPreview` |

`*` marks a required query parameter. Path parameters are listed in the route.
