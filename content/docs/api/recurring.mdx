---
title: Recurring transactions
description: Save recurring templates, override single occurrences and record each occurrence.
---

**Status: In testing.** Deployed in the API. Acceptance testing for this area is not complete.

Each occurrence is recorded with its own route.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/recurring` | Get Recurring | Signed-in user (Clerk bearer) | none | none | none | 200 array of `RecurringResponse` |
| `POST /api/v1/workspaces/{workspace_id}/recurring` | Save Recurring | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `RecurringWrite` | 200 `RecurringResponse` |
| `POST /api/v1/workspaces/{workspace_id}/recurring/overrides` | Save Recurring Override | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `RecurringOverrideWrite` | 200 `RecurringOverrideResponse` |
| `GET /api/v1/workspaces/{workspace_id}/recurring/page` | Recurring Page | Signed-in user (Clerk bearer) | none | `limit`, `cursor`, `q`, `sort`, `currency`, `active`, `type`, `account_id`, `category` | none | 200 `RecordPage_RecurringResponse_` |
| `GET /api/v1/workspaces/{workspace_id}/recurring/{template_id}/postings` | Recorded Occurrences | Signed-in user (Clerk bearer) | none | `limit`, `before_id` | none | 200 `OccurrencePage` |
| `POST /api/v1/workspaces/{workspace_id}/recurring/{template_id}/postings` | Record Occurrence | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `OccurrenceWrite` | 201 `OccurrenceReceipt` |
| `POST /api/v1/workspaces/{workspace_id}/recurring/{template_id}/postings/preview` | Occurrence Preview | Signed-in user (Clerk bearer) | none | none | `OccurrenceFacts` | 200 `OccurrencePreview` |

`*` marks a required query parameter. Path parameters are listed in the route.
