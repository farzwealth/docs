---
title: Attachments
description: Attach files, such as receipts, to a transaction.
---

**Status: In testing.** Deployed in the API. Acceptance testing for this area is not complete.

An upload runs in chunks. The file is then scanned and linked to a transaction. Downloads use a download ticket that the download route issues.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `POST /api/v1/workspaces/{workspace_id}/attachments/cleanup` | Cleanup | Signed-in user (Clerk bearer) | none | none | `AttachmentCleanup` | 200 `AttachmentCleanupResponse` |
| `GET /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}` | Status | Signed-in user (Clerk bearer) | none | none | none | 200 `AttachmentStatus` |
| `PUT /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}/chunks/{position}` | Put Chunk | Signed-in user (Clerk bearer) | none | none | `AttachmentChunkInput` | 200 `AttachmentStatus` |
| `POST /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}/download` | Download | Signed-in user (Clerk bearer) | none | none | `AttachmentDownload` | 200 (no body) |
| `POST /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}/download-ticket` | Ticket | Signed-in user (Clerk bearer) | none | none | none | 200 `AttachmentTicketResponse` |
| `POST /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}/finish` | Finish | Signed-in user (Clerk bearer) | none | none | `AttachmentAction` | 200 `AttachmentStatus` |
| `POST /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}/link` | Link | Signed-in user (Clerk bearer) | none | none | `AttachmentAction` | 200 `AttachmentStatus` |
| `POST /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}/remove` | Remove | Signed-in user (Clerk bearer) | none | none | `AttachmentAction` | 200 `AttachmentStatus` |
| `POST /api/v1/workspaces/{workspace_id}/attachments/{attachment_id}/rescan` | Rescan | Signed-in user (Clerk bearer) | none | none | `AttachmentAction` | 200 `AttachmentStatus` |
| `GET /api/v1/workspaces/{workspace_id}/transactions/{entry_id}/attachments` | List For Entry | Signed-in user (Clerk bearer) | none | `limit`, `before_id` | none | 200 `AttachmentPage` |
| `POST /api/v1/workspaces/{workspace_id}/transactions/{entry_id}/attachments` | Create | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `AttachmentInput` | 202 `AttachmentStatus` |

`*` marks a required query parameter. Path parameters are listed in the route.

## Models

Field types come from the contract. Money fields are decimal strings. Nullable fields can be `null`.

### `AttachmentCleanup`

| Field | Type | Required |
| --- | --- | --- |
| `confirmed` | boolean | yes |

### `AttachmentCleanupResponse`

| Field | Type | Required |
| --- | --- | --- |
| `purged` | integer | yes |
