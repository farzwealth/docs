These are recorded owned asset estimates and qualified event/history workflows. They do not certify ownership, licensed prices, live brokerage connections or a generic tax-lot/cost-basis service. See the complete index for investment/deposit settlement and correction routes. Do not guess the old `/assets/{asset_id}/lots` endpoint.

Private operations require an authorized Clerk user bearer and workspace membership. Optional/sensitive services retain their policy/entitlement/fresh-authentication gates.

| Complete route | Required operation headers (besides authentication) | Declared success |
| --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/assets` | — | 200 application/json AssetResponse[] |
| `POST /api/v1/workspaces/{workspace_id}/assets` | `Idempotency-Key` | 200 application/json AssetResponse |
| `GET /api/v1/workspaces/{workspace_id}/assets/{asset_id}/valuations` | — | 200 application/json AssetValuationResponse[] |
| `GET /api/v1/workspaces/{workspace_id}/assets/{asset_id}/investment-position` | — | 200 application/json InvestmentPosition |

## Exact request/response models

These JSON Schema definitions are generated from the verified contract, not sample financial records. Resolve `$ref` entries through [OpenAPI JSON](/openapi.json). All query/body constraints and additional operations appear in the [complete index](/docs/api/endpoints).
