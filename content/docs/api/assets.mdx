---
title: Assets, investments and vehicles
description: Save assets, lifecycle events, investment events, settlements, deposit payouts and valuations.
---

**Status: In testing.** Deployed in the API. Acceptance testing for this area is not complete.

Assets include property, stocks, ETFs, crypto, metals, vehicles, deposits and other items. Each asset has one dated estimate. An estimate is not a bank or market confirmation.

The vehicle depreciation route returns an estimate and labels it as one.
