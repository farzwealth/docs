---
title: Market data and valuation
description: Public FX feed, instruments, quotes, manual quotes and valuation previews.
---

**Status: In testing** for the FX feed and manual quotes. **Planned** for live market data providers, which are not yet configured.

Until live providers are configured, a quote is manual or stale. Check the freshness fields before you use a value.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/market/fx` | Public Fx Feed | None (public) | none | none | none | 200 `FeedResponse` |
| `POST /api/v1/workspaces/{workspace_id}/fx-conversions` | Fx Conversion | Signed-in user (Clerk bearer) | none | none | `FXConversionInput` | 200 `FXConversionResponse` |
| `GET /api/v1/workspaces/{workspace_id}/fx-observations` | Get Fx Observations | Signed-in user (Clerk bearer) | none | none | none | 200 array of `FXObservationResponse` |
| `POST /api/v1/workspaces/{workspace_id}/fx-observations` | Save Fx Observation | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `FXWrite` | 200 `FXObservationResponse` |
| `GET /api/v1/workspaces/{workspace_id}/fx-observations/page` | get_fx_observations (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `GetFxObservationsPage` |
| `GET /api/v1/workspaces/{workspace_id}/market/assets/{asset_id}/history` | History | Signed-in user (Clerk bearer) | none | `as_of*`, `limit`, `cursor` | none | 200 `QuoteHistory` |
| `POST /api/v1/workspaces/{workspace_id}/market/assets/{asset_id}/manual-quotes` | Manual | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `ManualQuote` | 200 `QuoteObservation` |
| `GET /api/v1/workspaces/{workspace_id}/market/assets/{asset_id}/quote` | Quote | Signed-in user (Clerk bearer) | none | `as_of*` | none | 200 `QuoteView` |
| `POST /api/v1/workspaces/{workspace_id}/market/assets/{asset_id}/refreshes` | Refresh | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `RefreshRequest` | 202 `RefreshView` |
| `GET /api/v1/workspaces/{workspace_id}/market/assets/{asset_id}/valuation-preview` | Valuation Preview | Signed-in user (Clerk bearer) | none | `as_of*`, `expected_asset_revision*` | none | 200 `QuoteValuationPreview` |
| `GET /api/v1/workspaces/{workspace_id}/market/capabilities` | Capabilities | Signed-in user (Clerk bearer) | none | none | none | 200 `MarketCapabilities` |
| `GET /api/v1/workspaces/{workspace_id}/market/disclosure` | Disclosure | Signed-in user (Clerk bearer) | none | none | none | 200 `MarketDisclosure` |
| `GET /api/v1/workspaces/{workspace_id}/market/instruments` | Instruments | Signed-in user (Clerk bearer) | none | `query`, `limit`, `cursor` | none | 200 `InstrumentPage` |
| `POST /api/v1/workspaces/{workspace_id}/market/quote-coverage` | Coverage | Signed-in user (Clerk bearer) | none | none | `QuoteCoverageInput` | 200 `QuoteCoverage` |
| `GET /api/v1/workspaces/{workspace_id}/market/quotes` | Quotes for many held assets in one request | Signed-in user (Clerk bearer) | none | `as_of*`, `asset_id*` | none | 200 `BatchQuotes` |
| `GET /api/v1/workspaces/{workspace_id}/market/refreshes/{refresh_id}` | Status | Signed-in user (Clerk bearer) | none | none | none | 200 `RefreshView` |
| `POST /api/v1/workspaces/{workspace_id}/market/refreshes/{refresh_id}/cancel` | Cancel | Signed-in user (Clerk bearer) | none | none | none | 200 `RefreshView` |
| `POST /api/v1/workspaces/{workspace_id}/market/refreshes/{refresh_id}/execute` | Execute | Signed-in user (Clerk bearer) | none | none | none | 200 `RefreshView` |

`*` marks a required query parameter. Path parameters are listed in the route.
