## Base URL and workspace

Every route in this section starts with `https://api.farz.app/api/v1`. Routes that act on your money include a workspace ID in the path, as `/api/v1/workspaces/{workspace_id}/...`. Each person has one personal workspace. To find its ID, call `GET /api/v1/workspaces`. The list returns only workspaces you own.

## Authentication

Send the bearer token of the signed-in user in the `Authorization` header:

```http
Authorization: Bearer <token>
```

The token comes from the Farz app's sign-in. Developer routes and MCP use a different credential. See [authentication](/docs/concepts/authentication).

Some routes need no token. They are marked **None (public)** in each table. Webhook routes accept calls only from the named provider, with a signature.
