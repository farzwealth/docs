title: Unified API overview
description: The deployed /api/v1 contract and its declared operations.
---

The live first-party base URL is **https://api.farz.app/api/v1**. The generated contract contains132 declared paths and160 operations, including reads and writes. This is different from the earlier site's15-route, read-only planned developer API.

Use [the complete route index](/docs/api/endpoints) and [OpenAPI JSON](https://api.farz.app/openapi.json) for all query parameters, headers, request schemas and success statuses. Obtain a Clerk user bearer and authorized workspace ID from `/api/v1/me`; see [authentication](/docs/concepts/authentication).

| Guide | Live resource family |
| --- | --- |
|[Profile](/docs/api/profile)|`/api/v1/me`, eligibility, onboarding and setup|
|[Summary](/docs/api/summary)|Workspace `/dashboard`, `/cashflow` and `/allocation`|
|[Accounts](/docs/api/accounts)|Workspace `/accounts` and financial journal commands|
|[Transactions](/docs/api/transactions)|Workspace `/transactions`|
|[Assets](/docs/api/assets)|Workspace `/assets` and qualified investment event/history routes|
|[Liabilities](/docs/api/liabilities)|Workspace `/debts` and linked repayment/override routes|
|[Lending](/docs/api/lending)|Workspace `/lending`, actual reclaim and compensating corrections|
|[Budgets](/docs/api/budgets)|Workspace `/budgets`|
|[Goals](/docs/api/goals)|Workspace `/goals`|
|[Valuations](/docs/api/valuations)|Workspace `/valuation-snapshots`|
|[Reports](/docs/api/reports)|Workspace `/exports` tasks and protected downloads|

A declared optional provider route does not mean that provider is active. Live capabilities currently report developer API, MCP, billing, email, AI and general import integrations as unconfigured. Do not use `/api/developer/v1` or guess aliases such as `/summary` and `/reports`.

Accounts/other collections can be arrays; transaction paging is endpoint-specific. Success can be200 or201, and downloads can be CSV/JSON/HTML. The schema does not enumerate every runtime policy/conflict error.
