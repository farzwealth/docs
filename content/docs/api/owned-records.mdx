title: Owned-record exports
description: Current unified API contracts, workflow and activation boundaries.
---

These routes export20 selected financial/profile/consent record groups as paged JSON or CSV. They are not a complete portability archive or a restore format. They require current Clerk ownership and signed recent first-factor authentication on the manifest and every page; refreshing a JWT alone is insufficient. Free/manual users retain this access, including scoped export access while deactivated.

1. GET `/reports/owned-records/manifest/json` under the workspace. Repeated `sections` selects a subset; omission selects all20. Unknown or duplicate sections return422.
2. Keep the returned `manifest_token` private. The manifest contains an export UUID, counts, full-section digests and a15-minute expiry.
3. GET `/reports/owned-records/{section}/json?manifest_token=...&limit=25` or the sibling `/csv`. Follow `next_cursor` until null. Default25/maximum100; page size may change. JSON/CSV cursors are interchangeable within the same section/export.
4. Preserve Decimal strings. JSON supplies page and full-section SHA-256 digests; canonical sorted-key compact UTF-8 JSON permits independent continuity checks. CSV nests the typed record in `data_json`, preserving Unicode and exact strings.

Manifest/cursors bind identity, workspace, lifecycle, sequence, local date and record projections. Expiry, mutations, midnight or changed authority/projection returns409; restart from a fresh manifest. Tokens are not bearer credentials or public download URLs. Responses are no-store; exporting creates no financial movement or durable archive job. The response truthfully retains `complete_account_portability:false`.

| Complete route | Authentication | Required operation headers | Declared success |
| --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/reports/owned-records/manifest/json` | Clerk user bearer | — | 200 application/json ManifestResponse |
| `GET /api/v1/workspaces/{workspace_id}/reports/owned-records/{section}/json` | Clerk user bearer | — | 200 application/json ExportPage |
| `GET /api/v1/workspaces/{workspace_id}/reports/owned-records/{section}/csv` | Clerk user bearer | — | 200 text/csv |
