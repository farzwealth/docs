Prices are not set. Do not rely on any price shown in a route until payments go live.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/billing/availability` | Availability | Signed-in user (Clerk bearer) | none | none | none | 200 `BillingAvailability` |
| `POST /api/v1/workspaces/{workspace_id}/billing/identity` | Register | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | none | 200 `BillingIdentityResponse` |
| `GET /api/v1/workspaces/{workspace_id}/billing/offerings` | Offerings | Signed-in user (Clerk bearer) | none | none | none | 200 array of `BillingOffering` |
| `GET /api/v1/workspaces/{workspace_id}/billing/offerings/page` | offerings (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `OfferingsPage` |
| `POST /api/v1/workspaces/{workspace_id}/billing/operations` | Enqueue | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `BillingCommand` | 202 `BillingOperationResponse` |
| `GET /api/v1/workspaces/{workspace_id}/billing/operations/{operation_id}` | Get Operation | Signed-in user (Clerk bearer) | none | none | none | 200 `BillingOperationResponse` |
| `POST /api/v1/workspaces/{workspace_id}/billing/operations/{operation_id}/cancel` | Cancel | Signed-in user (Clerk bearer) | none | none | none | 200 `BillingOperationResponse` |
| `POST /api/v1/workspaces/{workspace_id}/billing/operations/{operation_id}/execute` | Execute | Signed-in user (Clerk bearer) | none | none | none | 200 `BillingOperationResponse` |
| `GET /api/v1/workspaces/{workspace_id}/billing/operations/{operation_id}/history` | History | Signed-in user (Clerk bearer) | none | none | none | 200 array of `BillingEventResponse` |
| `GET /api/v1/workspaces/{workspace_id}/billing/operations/{operation_id}/history/page` | history (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `HistoryPage` |
| `GET /api/v1/workspaces/{workspace_id}/billing/status` | Status | Signed-in user (Clerk bearer) | none | none | none | 200 `BillingState` |

`*` marks a required query parameter. Path parameters are listed in the route.

## Models

Field types come from the contract. Money fields are decimal strings. Nullable fields can be `null`.

### `BillingAvailability`

| Field | Type | Required |
| --- | --- | --- |
| `configured` | boolean | yes |
| `policy_version` | string (nullable) | no |
| `web_checkout_available` | boolean | no |
| `native_purchase_available` | boolean | no |
| `automatic_reconciliation_active` | boolean | no |
| `clerk_billing_used` | boolean | no |
