Public capability and health endpoints need no user token. Readiness verifies configured schema/runtime prerequisites; it is not a certificate of complete provider, recovery or native readiness. Capabilities are the current operational source for optional integration availability.

As checked16October2026, identity is configured, lending is available, and AI, billing, email, market, imports, personal API and MCP integrations report `not_configured`. Market FX declarations do not imply licensed live asset/metal feeds. Missing quotes remain unavailable, never invented zero values.

The API root GET/HEAD redirects to https://docs.api.farz.app. Actual `/api/v1` paths retain their own routing and authentication; the root redirect is outside the generated operation index.

| Complete route | Authentication | Required operation headers | Declared success |
| --- | --- | --- | --- |
| `GET /api/v1/health/live` | Public / handler-specific | — | 200 application/json |
| `GET /api/v1/health/ready` | Public / handler-specific | — | 200 application/json |
| `GET /api/v1/capabilities` | Public / handler-specific | — | 200 application/json CapabilitiesResponse |
| `GET /api/v1/market/fx` | Public / handler-specific | — | 200 application/json FeedResponse |
