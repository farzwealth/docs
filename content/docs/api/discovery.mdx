---
title: Capabilities and client compatibility
description: Which integrations are available, and whether a client version is supported.
---

`GET /capabilities` lists which integrations are available. Clients use it to show a disabled feature honestly instead of failing.

`GET /client-compatibility/{platform}` reads the client support list for one platform.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/capabilities` | Capabilities | None (public) | none | none | none | 200 `CapabilitiesResponse` |
| `GET /api/v1/client-compatibility/{platform}` | Read reviewed client support and optionally assess a stable version | None (public) | none | `version` | none | 200 `CompatibilityView` |

`*` marks a required query parameter. Path parameters are listed in the route.
