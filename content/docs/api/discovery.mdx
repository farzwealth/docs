title: Record browsing and sync
description: Current unified API contracts, workflow and activation boundaries.
---

The ten bounded collection pages (accounts plus nine record families) and cross-record search discover existing private records. Legacy array routes are unchanged. Default page size25/maximum100; page shape and filters are endpoint-specific. Search is normalized literal display-label matching, not fuzzy search of encrypted notes, bank numbers or arbitrary payloads.

Keep identity, workspace, filters and snapshot intact across cursors; changing page size is supported by these view cursors. Mutations, midnight, expiry or changed projections can return409; start a new traversal. Foreign resources remain inaccessible. Read [pagination](/docs/concepts/pagination) for the different legacy transaction contract.

Portfolio queries, immutable history/detail and sync state/change cursors expose minimized authorized backend projections. A sequence is a synchronization boundary, not permission to fetch another workspace. Preserve financial decimal strings, current lifecycle restrictions and no-store handling; these endpoints do not add background native sync or provider connectivity.
