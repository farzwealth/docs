---
title: Money you lent
description: Record loans you made, log repayments, and correct or reclaim a loan.
---

**Status: In testing.** Deployed in the API. Acceptance testing for this area is not complete.

Repayments and their reversals are separate routes.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/lending` | List Lending | Signed-in user (Clerk bearer) | none | none | none | 200 array of `LendingLoanResponse` |
| `POST /api/v1/workspaces/{workspace_id}/lending` | Record Lending | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `LendingAdvance` | 200 `LendingLoanResponse` |
| `GET /api/v1/workspaces/{workspace_id}/lending/page` | Lending Page | Signed-in user (Clerk bearer) | none | `limit`, `cursor`, `q`, `sort`, `currency`, `state`, `overdue` | none | 200 `RecordPage_LendingLoanResponse_` |
| `GET /api/v1/workspaces/{workspace_id}/lending/{loan_id}` | Get Lending | Signed-in user (Clerk bearer) | none | none | none | 200 `LendingLoanResponse` |
| `POST /api/v1/workspaces/{workspace_id}/lending/{loan_id}/correct-advance` | Correct Lending Advance | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `LendingCorrection` | 200 `LendingRepaymentResponse` |
| `POST /api/v1/workspaces/{workspace_id}/lending/{loan_id}/reclaim` | Reclaim Lending | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `LendingReclaim` | 200 `LendingRepaymentResponse` |
| `POST /api/v1/workspaces/{workspace_id}/lending/{loan_id}/reclaim-preview` | Repayment | Signed-in user (Clerk bearer) | none | none | `LendingReclaim` | 200 `RepaymentPreview` |
| `GET /api/v1/workspaces/{workspace_id}/lending/{loan_id}/repayments` | Lending Repayments | Signed-in user (Clerk bearer) | none | none | none | 200 array of `LendingRepaymentResponse` |
| `GET /api/v1/workspaces/{workspace_id}/lending/{loan_id}/repayments/page` | lending_repayments (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `LendingRepaymentsPage` |
| `POST /api/v1/workspaces/{workspace_id}/lending/{loan_id}/repayments/{repayment_id}/reversal` | Reverse Lending Repayment | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `LendingCorrection` | 200 `LendingRepaymentResponse` |

`*` marks a required query parameter. Path parameters are listed in the route.
