title: Lending and actual Reclaim
description: Verified unified API routes and exact declared models.
---

Record money already lent from an active bank/cash account as cash exchanged for a separately owned receivable. Reclaim records money **actually received**, partially or in full; it never initiates a payment or reminder. Positive amounts cannot exceed remaining owed; account currency/revisions, loan revision, date and received_confirmed are checked server-side. Repayment changes cash and receivable atomically without counting as income/spending. Correct the latest active repayment before earlier dependencies/original advance; generic journal reversal and manual-asset edits refuse linked loans. Use the same idempotency key on unchanged retries. Live desktop acceptance passed partial50/full250 on an advance300, final cash1000/owed0, unchanged income/spending and durable reload.

Private operations require an authorized Clerk user bearer and workspace membership. Optional/sensitive services retain their policy/entitlement/fresh-authentication gates.

| --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/lending` | — | 200 application/json LendingLoanResponse[] |
| `POST /api/v1/workspaces/{workspace_id}/lending` | `Idempotency-Key` | 200 application/json LendingLoanResponse |
| `GET /api/v1/workspaces/{workspace_id}/lending/{loan_id}` | — | 200 application/json LendingLoanResponse |
