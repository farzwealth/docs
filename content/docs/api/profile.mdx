---
title: Profile, onboarding and eligibility
description: Read and update the signed-in user, onboarding, workspace list, preferences and eligibility.
---

Routes for the signed-in user. Start with `GET /me`. Language values are `en`, `ar`, `fr` and `ru`. The Arabic, French and Russian text is an AI-reviewed draft until a human reviewer signs it off.

Personal sign-up is for adults aged 18 and over in AE, SA, BH, KW, QA and OM.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `POST /api/v1/eligibility/check` | Check Eligibility | None (public) | none | none | `EligibilityInput` | 200 `EligibilityResponse` |
| `GET /api/v1/me` | Me | Signed-in user (Clerk bearer) | none | none | none | 200 `ProfileResponse` |
| `PATCH /api/v1/me` | Update Personal Profile | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `Preferences` | 200 `ProfileResponse` |
| `GET /api/v1/me/reauthentication-status` | Current | Signed-in user (Clerk bearer) | none | none | none | 200 `ReauthenticationStatus` |
| `POST /api/v1/onboarding` | Onboarding | Signed-in user (Clerk bearer) | none | none | `OnboardingInput` | 200 `ProfileResponse` |
| `GET /api/v1/workspaces` | List the caller's own workspaces (paged) | Signed-in user (Clerk bearer) | none | `limit`, `cursor` | none | 200 `WorkspaceListPage` |
| `PATCH /api/v1/workspaces/{workspace_id}/preferences` | Preferences | Signed-in user (Clerk bearer) | `Idempotency-Key` | none | `Preferences` | 200 `ProfileResponse` |
| `GET /api/v1/workspaces/{workspace_id}/settings` | Read Settings | Signed-in user (Clerk bearer) | none | none | none | 200 `SettingsResponse` |
| `POST /api/v1/workspaces/{workspace_id}/setup` | Setup Progress | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `SetupProgress` | 200 `SetupState` |

`*` marks a required query parameter. Path parameters are listed in the route.
