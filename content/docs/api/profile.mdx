Use `/me.workspace_id`; it is null before onboarding. Current personal signup uses self-declared age13+ throughout AE/SA/BH/KW/QA/OM, with no guardian verification. Store age band/policy version rather than exact age/DOB; legacy DOB input remains compatible. Backend-owned setup completion survives reload/direct links. This does not certify MFA, AI or billing activation.

Private operations require an authorized Clerk user bearer and workspace membership. Optional/sensitive services retain their policy/entitlement/fresh-authentication gates.

| Complete route | Required operation headers (besides authentication) | Declared success |
| --- | --- | --- |
| `GET /api/v1/me` | — | 200 application/json ProfileResponse |
| `POST /api/v1/eligibility/check` | — | 200 application/json EligibilityResponse |
| `POST /api/v1/onboarding` | — | 200 application/json ProfileResponse |
| `PATCH /api/v1/workspaces/{workspace_id}/preferences` | — | 200 application/json ProfileResponse |
| `POST /api/v1/workspaces/{workspace_id}/setup` | `Idempotency-Key` | 200 application/json SetupState |
