title: Account actions and history
description: Change the state of one account, read its history and check job health.
---

The account actions route changes an account's state. The account history route lists past actions.

The terms-acceptance routes let an adult account owner accept the current published Terms and Privacy Policy again. An account created before the current text was published holds an earlier version. The assistant and statement reading ask for the current Terms, and when the stored acceptance is older they answer `TERMS_UPDATE_REQUIRED` (see the `reason` field in the [assistant guide](/docs/api/assistant)).

## Accept the current Terms

1. `GET /api/v1/workspaces/{workspace_id}/terms-acceptance` returns the version in force, the SHA-256 of the text in the language you ask for (`locale`), and `current`, which is `true` when your stored acceptance is the current one. It also returns `revision`, which you send back when you accept.
2. `POST` the same path with the `revision` as `expected_revision`, the `locale`, both versions and both text digests you were shown, and `confirmed: true`. Send an `Idempotency-Key` header.
3. The response is the new state. The call answers `409` when the published text has moved on since the digests you sent, or when another device accepted first. Fetch the state again and show the text again before retrying.

If the account is already current, the call changes nothing and returns the state, so a double click or a second device is harmless. Only the account owner can accept, and only an adult account.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/account` | Account Status | Signed-in user (Clerk bearer) | none | none | none | 200 `AccountState` |
| `POST /api/v1/workspaces/{workspace_id}/account/actions` | Account Action | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `AccountAction` | 200 `AccountState` |
| `GET /api/v1/workspaces/{workspace_id}/account/history` | Account History | Signed-in user (Clerk bearer) | none | `offset`, `limit` | none | 200 array of `AccountEvent` |
| `GET /api/v1/workspaces/{workspace_id}/terms-acceptance` | Terms Acceptance Status | Signed-in user (Clerk bearer) | none | `locale` | none | 200 `TermsAcceptanceState` |
| `POST /api/v1/workspaces/{workspace_id}/terms-acceptance` | Accept Current Terms | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `TermsAcceptanceInput` | 200 `TermsAcceptanceState` |
| `GET /api/v1/workspaces/{workspace_id}/jobs/health` | Health | Signed-in user (Clerk bearer) | none | none | none | 200 `QueueHealth` |

`*` marks a required query parameter. Path parameters are listed in the route.
