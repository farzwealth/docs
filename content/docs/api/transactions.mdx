GET transactions uses `TransactionPage` with items/next_offset/next_cursor; limit defaults100, max100. Optional loan_id/lending_repayment_id identify lending records. Generic reversals refuse linked lending; use lending-specific correction routes. See [pagination](/docs/concepts/pagination).

Private operations require an authorized Clerk user bearer and workspace membership. Optional/sensitive services retain their policy/entitlement/fresh-authentication gates.

| Complete route | Required operation headers (besides authentication) | Declared success |
| --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/transactions` | — | 200 application/json TransactionPage |
| `POST /api/v1/workspaces/{workspace_id}/journal/reversals` | `Idempotency-Key` | 201 application/json TransactionResponse |
