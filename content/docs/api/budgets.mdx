title: Budgets
description: Read and save monthly budgets by category, and repeat them to later months.

Preview a repeat before you apply it.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/v1/workspaces/{workspace_id}/budgets` | Get Budgets | Signed-in user (Clerk bearer) | none | `period*` | none | 200 array of `BudgetResponse` |
| `POST /api/v1/workspaces/{workspace_id}/budgets` | Update Budget | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `BudgetWrite` | 200 `BudgetResponse` |
| `GET /api/v1/workspaces/{workspace_id}/budgets/page` | Budget Page | Signed-in user (Clerk bearer) | none | `limit`, `cursor`, `q`, `sort`, `currency`, `period*`, `category`, `over_budget` | none | 200 `RecordPage_BudgetResponse_` |
| `POST /api/v1/workspaces/{workspace_id}/budgets/repeat` | Repeat | Signed-in user (Clerk bearer) | `Idempotency-Key (required)` | none | `BudgetRepeatWrite` | 200 `BudgetRepeatReceipt` |
| `POST /api/v1/workspaces/{workspace_id}/budgets/repeat/preview` | Preview | Signed-in user (Clerk bearer) | none | none | `BudgetRepeatSelection` | 200 `BudgetRepeatPreview` |

`*` marks a required query parameter. Path parameters are listed in the route.
