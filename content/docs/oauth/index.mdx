---
title: OAuth for MCP
description: How an AI client signs in to the Farz MCP server with OAuth, and what a token can and cannot do.
---

The Farz MCP server uses OAuth 2.0 with PKCE. Clerk, Farz's identity provider, runs the sign-in and issues tokens. Farz checks each request and checks your approval in the Farz app.

## Discovery

Clients find the server's settings from these URLs:

| URL | Purpose |
| --- | --- |
| `https://mcp.farz.app/.well-known/oauth-protected-resource/mcp` | The protected resource metadata for the MCP server. It names the authorization server. |
| `https://clerk.farz.app/.well-known/oauth-authorization-server` | The authorization server metadata: endpoints, supported methods and client registration. |

Read the endpoints from the metadata. Do not hard-code them.

## Authorization request

| Parameter | Requirement |
| --- | --- |
| `response_type` | `code` |
| `code_challenge_method` | `S256` only. The server does not accept `plain`. |
| `code_challenge` | A PKCE challenge for this request |
| `state` | A fresh, unpredictable value. Check that it matches on return. |
| `resource` | `https://mcp.farz.app/mcp`. Send it so the token is issued for this server only. |
| `client_id` | Your client, registered by client ID metadata document |

The server advertises client ID metadata documents. Dynamic client registration is off. A client that cannot use metadata documents cannot connect until Farz enables registration. Registration is not yet confirmed for every client.

## Tokens

- Access tokens are opaque strings, not JWTs. Clerk sets their lifetime to 1 day.
- Clerk does not expire refresh tokens. This is Clerk's default and cannot be changed in this setup.
- Every request is checked remotely. A revoked token stops working on its next request. Nothing is cached on the Farz side.

A token proves who you are and which client is calling. A token alone does not give access to your finance data. Your approval in the Farz app controls what the client can read. The approval expires within 90 days.

## Revoke access

Open the Farz app's connector settings and revoke the assistant. Revocation takes effect on the next request. Ending a chat or closing a stream does not revoke the approval.

## Errors

The MCP server returns standard OAuth and MCP error responses. A `401` response includes a challenge with `scope="openid"`. Do not log a token, an authorization code or a verifier.
