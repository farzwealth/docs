---
title: OAuth availability
description: Current integration status; no working setup is advertised.
---

Third-party OAuth delegation is **unavailable**. The old protected-resource discovery, `auth.farz.app/oauth/authorize`, token/refresh/revocation URLs and opaque-token examples were not verified live endpoints. Current production authentication is a supported Clerk user session bearer for the first-party `/api/v1` API. Future PKCE/delegated access requires separate implementation and security/activation evidence; no authorization server flow or token lifetime is promised today.

See [current API availability](/docs).
