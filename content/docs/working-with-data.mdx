Get the profile with `GET /api/v1/me`, then use its authorized `workspace_id`. Accounts are a plain array; transactions use `items`, `next_cursor` and `next_offset`. There is no universal `Money`, `Page` or `has_more` envelope.

```python
from decimal import Decimal

# account is one AccountResponse from an authorized accounts request.
balance = Decimal(account["balance"])
currency = account["currency"]
```

Use the [first-party request examples](/docs/developer/examples), [pagination guide](/docs/concepts/pagination) and [schema](/docs/api/schemas). Missing converted/estimated values stay missing. Net worth and spending come from the backend's financial rules; do not count loan advances or repayments as spending/income.

Free users never invoke AI. PDF/image extraction is intended to use approved native model vision, never OCR, behind independent consent, entitlement, preparation/privacy/cost and confirmation gates. Live AI/general import integrations currently report unconfigured; schema visibility is not activation evidence.
