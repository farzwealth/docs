These are the features Farz plans to finish before the Farz app opens to the public. The status shown is the status today. It can change.

**The Farz app is not public yet.** Nothing on this page is generally available. A status of In testing means the feature is deployed and being checked. It does not mean you can use it now without an invitation.

## Status labels

| Label | Meaning |
| --- | --- |
| **Live** | Working in production and available to the people it is meant for. |
| **In testing** | Deployed. Acceptance testing is not finished, or access is limited to a few testers. |
| **Planned** | Not built, not deployed, or not enabled. Do not call it. |

## Order of work

Farz plans to finish the API first, then the web app, then the Android app, then the iPhone app. Payments come after the beta and the release. No date is set in these docs. Dates will be published when the owner announces them.
