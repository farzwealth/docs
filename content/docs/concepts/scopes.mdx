---
title: Scopes
description: The read scopes for the personal developer API and the MCP tools, and the rule for combining them.
---

A scope is a read permission that you grant to a credential. A scope lets a credential read one kind of data. It never allows a write.

## Developer API scopes

| Scope | Lets the credential read |
| --- | --- |
| `profile:read` | Locale, base currency and timezone |
| `accounts:read` | Your accounts, as masked summaries |
| `transactions:read` | Your posted transactions in a date range |

The developer API does not return account balances. Its account summaries have an ID, a currency, a kind, up to four masked digits, a revision and an archived flag.

## MCP tool scopes

Each MCP tool needs one scope. The tool list is in [MCP tools](/docs/mcp/tools).

| Scope | Tools |
| --- | --- |
| `profile:read` | `get_preferences` |
| `accounts:read` | `list_accounts` |
| `transactions:read` | `list_transactions` |
| `assets:read` | `list_assets` |
| `liabilities:read` | `list_liabilities` |
| `budgets:read` | `get_budget` |
| `goals:read` | `list_goals` |
| `valuations:read` | `get_valuation_history` |
| `reports:read` | `get_financial_summary`, `get_report_data` |

## Choosing scopes

Grant only the scopes you need. A connector or key with a narrow scope set cannot read the other domains, even when they exist in your account.
