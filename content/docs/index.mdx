## Features

<Callout type="info">
  Fumadocs includes out-of-the-box full-text search, automatic table of contents, MDX support, and automated Open Graph image generation.
</Callout>

- **Fast & Responsive**: Built with Next.js App Router and React 19.
- **Full MDX Power**: Embed interactive React components seamlessly in Markdown.
- **Search & Indexing**: Built-in full-text search API powered by Fumadocs.
- **AI & LLM Ready**: Preconfigured `/llms.txt` and `/llms-full.txt` endpoints for AI agents and LLM scrapers.
