The Farz API is the service behind the Farz app. These docs describe its routes and the parts you can reach from outside the app.

## What you can reach

| Surface | What it is |
| --- | --- |
| [Farz app API](/docs/api/overview) at `/api/v1` | The routes the Farz app uses with a signed-in user's token. The API reference covers every route in the current contract. |
| [Personal developer REST API](/docs/developer/reference) at `/api/developer/v1` | Three read-only routes for your own profile, accounts and transactions. |
| [Remote MCP server](/docs/mcp) at `https://mcp.farz.app/mcp` | Read-only tools for an AI assistant that you approve. |
| [Personal API keys](/docs/api/integrations) | Keys for the personal developer REST API. |
| Payments | Paid plans from Stripe, Ziina, Google Play or RevenueCat. |

Read the [roadmap](/docs/roadmap) for the full list of features planned before launch.

## Who can use the developer surfaces

The personal developer REST API and the MCP server need a **Paid** plan or a **staff-granted beta access grant**. Free and Trial accounts do not qualify on their own. Payments are not live, so Paid plans are not yet available to buy. Staff can grant beta access for up to 90 days.

## Reading the API reference

Each API reference page lists routes in a table. The table shows the method and path, the operation name, the authentication, any required headers, the query parameters, the request body model and the success response. Models are listed below each table. Money values are decimal strings. The [conventions](/docs/concepts/conventions) page explains the common rules.
