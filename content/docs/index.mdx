Use the **Farz API** to read your personal accounts, transactions, assets, and financial reports from a private application. Get started with a user API key from your Clerk account settings, or connect an AI assistant with Model Context Protocol (MCP) and OAuth.

<Callout type="warn" title="Contract Status: Pre-release">
  This guide describes the intended public API contract for the finished product. The developer REST and MCP surfaces are currently in active development. Endpoint paths, response models, and examples below represent proposed contracts; please confirm them against the published OpenAPI specification and release notes when the API becomes generally available.
</Callout>

## Service Coordinates

| Property | Value |
| :--- | :--- |
| **REST Base URL** | `https://api.farz.app/api/developer/v1` |
| **MCP URL** | `https://api.farz.app/mcp` |
| **API Version** | `v1` |
| **Access Model** | Read-only, single-user personal workspace |
| **Last Updated** | 9 October 2026 |
