**Status: Planned for the developer API. In testing for MCP.**

| Problem | What to check |
| --- | --- |
| `401 UNAUTHENTICATED` | The key is wrong, expired or revoked. Check the value in your environment. Create a new key if the old one is revoked. |
| `403 PAID_REQUIRED` | Your plan does not include the developer API. Trial accounts do not qualify. A staff-granted beta grant also works. |
| `403 INSUFFICIENT_SCOPE` | The key lacks the scope for this route. Create a key with `accounts:read` or `transactions:read`. |
| `503 INTEGRATION_UNAVAILABLE` | The developer API is off, or paused for your account. Try again later. |
| `409 CURSOR_EXPIRED` | The cursor is older than 15 minutes. Start again without a cursor. |
| `422 INVALID_CURSOR` | The cursor was changed or belongs to another query. Start again without a cursor. |
| `422 INVALID_QUERY` | A date is missing, the range is more than 366 days, or the end is before the start. |
| `429 RATE_LIMITED` | You sent too many requests. Wait for `Retry-After`, then retry with backoff. |
| An account or transaction you can see in the app is missing | The developer API shows only records that were fully private when posted. Shared or mixed records are excluded. Older history may be incomplete. |
| An empty list | The request worked. No records match your filters. Check the dates. |
| MCP tool missing | Check the scopes you approved, and that your plan or beta grant is active. |
| MCP `CONNECTOR_NOT_APPROVED` | Approve the assistant in the Farz app's connector settings. |

## Still stuck

Open a support ticket in the Farz app. Include the `request_id` from the error and the time of the request. Do not send your key, tokens, full response bodies or account numbers.
