---
title: Troubleshooting
description: Resolve API routing, authentication and financial conflicts safely.
---

| Symptom | Check |
| --- | --- |
| `/api/developer/v1/...` returns404 | The developer surface is unavailable; use the first-party contract only in authorized integrations. |
|401 on `/api/v1/me` | Obtain a current supported Clerk user token; never use a publishable/secret key as a bearer. |
| Workspace is null | Finish real onboarding in the dashboard. |
|403 | Check workspace membership, eligibility, entitlement and recent-authentication requirements. |
|409 on a command | Refresh revisions/history and review; preserve unchanged retry keys. |
|429 | Honor `Retry-After`; reduce request fan-out and polling. |
|503 | Check readiness/capabilities and required dependencies; optional services may be unconfigured. |
| Browser CORS failure | Only the dashboard origin is currently approved for private financial requests. |
| Report not ready | Inspect the scoped export task; do not treat task creation as a completed download. |

Share only status/error code and request ID when reporting a failure. Never send bearer tokens, API/Clerk secrets, request headers or private financial payloads.
