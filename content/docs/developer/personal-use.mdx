---
title: Personal use and developer availability
description: Use the live dashboard while developer-key access is deferred.
---

Use [dash.farz.app](https://dash.farz.app) to sign in and track your own workspace. Ordinary first-party money tracking does not require a developer API key or an active Paid developer entitlement.

Paid personal developer keys remain deferred and must be Clerk-issued when implemented. The payment entitlement must come from backend-verified provider state; Farz does not use Clerk Billing. There is no currently supported key-creation UI, third-party OAuth grant or MCP setup to configure from these docs.

See [current availability](/docs) and the [authentication contract](/docs/concepts/authentication).
