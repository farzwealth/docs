title: Developer REST reference
description: The routes of the personal developer API, with their models.
---

The routes below come from the contract. A route that is listed here is not proof that the API is enabled for your account. Use the [quickstart](/docs/quickstart) to start once it is enabled.

## Endpoints

| Route | Operation | Auth | Required headers | Query | Request body | Success |
| --- | --- | --- | --- | --- | --- | --- |
| `GET /api/developer/v1/accounts` | Accounts | Personal API key | none | `limit`, `cursor` | none | 200 `PersonalAccountPage` |
| `GET /api/developer/v1/profile` | Profile | Personal API key | none | none | none | 200 `PersonalPreferences` |
| `GET /api/developer/v1/transactions` | Transactions | Personal API key | none | `limit`, `cursor`, `start*`, `end*` | none | 200 `PersonalTransactionPage` |
| `GET /api/developer/v1/summary` | Summary | Personal API key | none | none | none | 200 `SummaryView` |
| `GET /api/developer/v1/reports/net-worth` | Net Worth Report | Personal API key | none | none | none | 200 `ReportView` |
| `GET /api/developer/v1/assets` | Assets | Personal API key | none | `limit`, `cursor` | none | 200 `AssetPage` |
| `GET /api/developer/v1/liabilities` | Liabilities | Personal API key | none | `limit`, `cursor` | none | 200 `LiabilityPage` |
| `GET /api/developer/v1/liabilities/{liability_id}/schedule` | Liability Schedule | Personal API key | none | `limit`, `cursor` | none | 200 `SchedulePage` |
| `GET /api/developer/v1/budgets` | Budgets | Personal API key | none | `limit`, `cursor`, `month` | none | 200 `BudgetPage` |
| `GET /api/developer/v1/goals` | Goals | Personal API key | none | `limit`, `cursor` | none | 200 `GoalPage` |
| `GET /api/developer/v1/valuations` | Valuations | Personal API key | none | `limit`, `cursor`, `asset_id`, `start`, `end` | none | 200 `ValuationPage` |

`*` marks a required query parameter.
