## Python: list accounts and count them by currency

This example uses only the Python standard library. It follows `next_cursor` until it is `null`, and it counts accounts. It prints counts, not account details.

```python
import json
import os
import urllib.parse
import urllib.request
from collections import Counter

BASE = "https://api.farz.app/api/developer/v1"
TOKEN = os.environ["FARZ_API_KEY"]


def get_page(cursor=None):
    params = {"limit": 50}
    if cursor:
        params["cursor"] = cursor
    url = f"{BASE}/accounts?{urllib.parse.urlencode(params)}"
    request = urllib.request.Request(
        url,
        headers={"Authorization": f"Bearer {TOKEN}", "Accept": "application/json"},
    )
    with urllib.request.urlopen(request, timeout=20) as response:
        return json.load(response)


seen_ids = set()
by_currency = Counter()
cursor = None
while True:
    page = get_page(cursor)
    for account in page["items"]:
        if account["id"] in seen_ids:
            continue  # Skip a duplicate that a re-sent page can bring.
        seen_ids.add(account["id"])
        by_currency[account["currency"]] += 1
    cursor = page["next_cursor"]
    if cursor is None:
        break

print(f"Read {len(seen_ids)} accounts.")
for currency, count in sorted(by_currency.items()):
    print(f"{currency}: {count}")
```

The script does not handle a `429` or `503` response. Add a bounded retry that honors `Retry-After` before you run it on a schedule. See [rate limits](/docs/concepts/rate-limits).

## TypeScript: read one page of transactions

This example needs Node.js 18 or later, for the built-in `fetch`. It keeps the amount as a string.

```ts
type Transaction = {
  id: string;
  type: string;
  amount: string;
  currency: string;
  occurred_on: string;
  account_id: string;
  to_account_id: string | null;
};
type Page<T> = { items: T[]; next_cursor: string | null; revision: number };

const token = process.env.FARZ_API_KEY;
if (!token) throw new Error("FARZ_API_KEY is not set");

const url = new URL("https://api.farz.app/api/developer/v1/transactions");
url.searchParams.set("start", "2026-10-01");
url.searchParams.set("end", "2026-10-10");
url.searchParams.set("limit", "50");

const response = await fetch(url, {
  headers: { Authorization: `Bearer ${token}`, Accept: "application/json" },
  cache: "no-store",
  signal: AbortSignal.timeout(20_000),
});
if (!response.ok) {
  // The body has code, message and request_id. Log only those fields.
  throw new Error(`Farz request failed with status ${response.status}`);
}

const page = (await response.json()) as Page<Transaction>;
for (const item of page.items) {
  // Keep amounts as strings. Use a decimal library for any sum.
  console.log(item.occurred_on, item.type, item.amount, item.currency);
}
```

Do not convert `amount` with `Number()` for totals. Use a decimal library.
