Learn how to contribute to the Farz documentation and structure your content.

## Adding Documentation Pages

All documentation pages are written in MDX and located in the `content/docs` directory.

<Steps>
  <Step>
    ### Create an MDX File
    
    Add a new `.mdx` file inside `content/docs/`. For example, `content/docs/my-feature.mdx`.
  </Step>

  <Step>
    ### Add Frontmatter
    
    Every page requires a frontmatter block at the top with at least a `title` and `description`:
    
    ```mdx
    ---
    title: My Feature
    description: Guide on how to use My Feature
    ---
    ```
  </Step>

  <Step>
    ### Update Navigation
    
    Add your page slug to `content/docs/meta.json` in the `pages` array to position it in the sidebar:
    
    ```json
    {
      "pages": [
        "index",
        "getting-started",
        "my-feature"
      ]
    }
    ```
  </Step>
</Steps>

## Running Locally

To start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000/docs](http://localhost:3000/docs) in your browser to view your live changes with fast refresh.
