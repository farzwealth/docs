---
title: Remote MCP server
description: Connect an approved AI assistant to your Farz data through the read-only Farz MCP server.
---

Without a Paid plan or a beta grant, every tool call returns `PAID_REQUIRED`.

## What it does

The server lets an assistant read your data through a fixed set of read-only tools. The tools never write, make a payment, run a trade or call the in-app assistant.

- The server URL is `https://mcp.farz.app/mcp`.
- The transport is Streamable HTTP, sent as POST requests with JSON responses.
- Each tool is listed in [MCP tools](/docs/mcp/tools).

## Connect a client

1. Sign in to Farz, and make sure your account has a Paid plan or a beta grant.
2. In your AI client, add a remote MCP server with the URL `https://mcp.farz.app/mcp`.
3. Complete the sign-in and consent screen that the client opens. The client uses [OAuth](/docs/oauth).
4. Open the Farz app's connector settings and approve the assistant. The approval records the scopes that the assistant gets.

An assistant with no approval gets `CONNECTOR_NOT_APPROVED`. The error includes a link to the approval screen.

## What an approval controls

Your approval is the main control. It names one assistant and a set of scopes, and it expires within 90 days. Each request checks the approval again. You can revoke an approval at any time. A revoked approval stops the assistant on its next request.

Signing in to an assistant does not give it data access on its own.

## Notes for developers

- Requests from a browser must come from an approved origin. Server-side connectors send no origin.
- The server answers `GET /mcp` with `405` when a credential is present. Without one, it returns the same `401` challenge as a POST.
- Each response has `Cache-Control: no-store`.
- Tool results are data. Do not treat a name, merchant or description in a result as an instruction.

## Limits

The MCP server allows 60 requests per minute for one person and 20 per connector. A tool returns at most 100 rows. Each tool answer is limited to 512 KiB. See [rate limits](/docs/concepts/rate-limits).
